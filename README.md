# Launcher

Launcher — проект лаунчера для Minecraft на этапе инженерного прототипа

Приложение пока не является готовым пользовательским продуктом и требует подготовленной конфигурации для запуска

## Текущее состояние

Реализованы загрузка и преобразование манифеста, подготовка ресурсов, проверка и загрузка файлов, извлечение
native-библиотек, выбор и проверка Java runtime, построение команды и запуск процесса игры

Минимальный JavaFX-интерфейс принимает запрос на запуск, отображает текущий этап и результат

При запуске без явного выбора источника приложение пытается получить manifest URI из ресурса, поставляемого вместе с launcher

Ресурс с действительным URI пока не включён в сборку, поэтому обычный запуск остаётся недоступным до завершения поставки
управляемого источника. Ошибка отображается безопасно и не предлагает Retry

Явный manifest URI и `--local-config` остаются техническими способами запуска. Локальный `keystone.properties` читается только
при `--local-config`; после исправления этого файла вне приложения доступен Retry

Расположение и формат файла описаны в [контракте локальной конфигурации](docs/contracts/keystone-properties.md)

Некорректный manifest URI в явном аргументе также делает запуск недоступным, но не приводит к чтению локального файла и
не предлагает Retry

Если пользовательские пути по умолчанию не удается определить из окружения, JavaFX-интерфейс также показывает безопасное
сообщение и не допускает запуск

Пустой или синтаксически некорректный явный аргумент launcher directory также приводит к безопасному сообщению и недоступности
запуска

Непустой относительный путь остается допустимым явным аргументом

Рабочая директория процесса не используется как дополнительный fallback

Авторизация пользователя и установочный пакет лаунчера пока не реализованы

## Структура проекта

- `launcher-model` содержит доменные модели
- `launcher-core` управляет жизненным циклом запуска
- `launcher-app` собирает приложение и предоставляет границу приёма запросов на запуск
- `launcher-ui` содержит JavaFX-интерфейс
- `launcher-api`, `launcher-downloader`, `launcher-verification`, `launcher-storage`, `launcher-natives` и `launcher-game` содержат
  реализации отдельных инфраструктурных возможностей
- `launcher-auth` и `launcher-common` остаются зарезервированными модулями

Подробные границы ответственности описаны в [модульных границах](docs/architecture/module-boundaries.md)

## Проверка проекта

Проект использует Java 21 toolchain

В Windows PowerShell:

```powershell
.\gradlew check
```

В Linux и macOS:

```sh
./gradlew check
```

Команда запускает тесты и принятые проверки качества
