# Сценарий 001: поддержка нескольких игровых профилей

> Статус: исторический архитектурный сценарий

Документ отражает раннюю оценку изменяемости архитектуры и не является источником актуальной информации о текущих
модульных границах

Некоторые упомянутые компоненты, включая `HashVerifier`, были удалены или заменены в последующих итерациях

Перед реализацией profile flow сценарий должен быть пересмотрен относительно актуальных manifest, runtime identity,
storage и presentation boundaries

---

## Историческая оценка

### Требование

Поддержка нескольких игровых профилей

### Измененные компоненты

- launcher-ui
- LaunchContext
- ManifestService

### Не изменилось

- Verification
- Download
- FileStorage
- HashVerifier
- LauncherEngine

### Вывод

Архитектура выдержала изменение
