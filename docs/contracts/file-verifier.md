# FileVerifier Contract

## Ответственность

Проверяет один локальный файл относительно одной записи Manifests

## Входные данные

- Локальный путь к файлу
- FileEntry из Manifest

## Выходные данные

FileVerificationResult.

## Гарантии

- Не изменяет файловую систему.
- Не скачивает данные.
- Не хранит состояние между проверками
- Проверяет только один файл

## Зависимости

FileVerifier может использовать

- FileMetadataReader для проверки существования и размера файла
- HashService для вычисления SHA-256

FileVerifier не должен использовать:

- Manifest
- VerificationPlan
- DirectoryProvider
- UI components

## Ошибки

Если файл отсутствует, возвращается статус MISSING

Если файл существует, но размер не совпадает, возвращает статус OUTDATED

Если файл существует, размер совпадает, но SHA-256 не соответствует ожидаемому, возвращается статус CORRUPTED

Если файл существует, размер совпадает и SHA-256 соответствует ожидаемому, возвращается статус VALID

Непредвиденные ошибки чтения файла считаются технической ошибкой verification-слоя и
обрабатываются вызывающим слоем
