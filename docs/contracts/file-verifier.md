# FileVerifier Contract

## Ответственность

Проверяет один локальный файл относительно одной записи Manifests

## Входные данные

- Локальный путь к файлу
- FileEntry из Manifest

## Выходные данные

FileVerificationResult.

## Гарантии

- Не изменяет файловую систему.
- Не скачивает данные.
- Не хранит состояние между проверками
- Проверяет только один файл

## Ошибки

Если файл отсутствует, возвращается статус MISSING

Если файл существует, но не соответствует ожидаемому hash, возвращается статус CORRUPTED

Непредвиденные ошибки чтения файла считаются технической ошибкой verification-слоя и
обрабатываются вызывающим слоем
