# Контракт keystone.properties

## Назначение

`keystone.properties` предоставляет manifest URI для запуска без явно заданного URI в аргументах приложения

Файл читается модулем `launcher-app` до создания `LauncherConfiguration`

---

## Формат

Файл читается в UTF-8 как Java properties

Для текущего startup используется свойство `manifest.uri`

```properties
manifest.uri=http://127.0.0.1:8080/manifest.json
```

Пример предполагает запущенный локальный HTTP-сервер и не является источником манифеста по умолчанию

---

## Расположение

- Windows: `%LOCALAPPDATA%\keystone\keystone.properties`
- Linux: `XDG_CONFIG_HOME/keystone/keystone.properties`, если `XDG_CONFIG_HOME` задает абсолютный путь; иначе
  `.config/keystone/keystone.properties` внутри домашнего каталога пользователя
- macOS: `Library/Application Support/keystone/keystone.properties` внутри домашнего каталога пользователя

Отсутствующий файл не создается автоматически

---

## Проверка и приоритет

`manifest.uri` должен содержать абсолютный HTTP(S) URI с host

Отсутствующий файл, отсутствие или пустое значение `manifest.uri`, ошибка чтения или разбора файла и некорректный URI
приводят к ожидаемой ошибке startup-конфигурации

Проверка URI не подтверждает доступность сервера или корректность содержимого манифеста

Явно заданный manifest URI имеет приоритет: в этом случае `keystone.properties` не читается и не используется как fallback
при ошибке аргумента

---

## Граница текущего интерфейса

При ошибке локального источника пользователь исправляет файл вне приложения и повторно подготавливает конфигурацию через
Retry

Интерфейс пока не создает и не редактирует файл самостоятельно

При ошибках явного manifest URI, явно заданной launcher directory и определения пользовательских путей действие Retry
недоступно
