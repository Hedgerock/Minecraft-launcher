# Контракт локального инструмента публикации манифеста

## Назначение

`launcher-publisher` локально подготавливает отдельную подпись управляемого манифеста и публичный ключ для проверки этой
подписи в launcher

Инструмент не создает манифест или хранилище ключей, не проверяет игровые ресурсы и не публикует файлы по URI

---

## Команды

```text
sign <keystore.p12> <alias> <manifest.json> <manifest.sig>
export-public-key <keystore.p12> <alias> <public-key.der>
```

`sign` подписывает исходные байты указанного файла манифеста алгоритмом Ed25519 и создает отдельный бинарный файл подписи

`export-public-key` извлекает соответствующий публичный ключ в формате SubjectPublicKeyInfo с DER-кодированием

Обе команды используют запись закрытого ключа, выбранную по `alias` в хранилище PKCS#12

---

## Защита ключа

Хранилище с закрытым ключом находится вне репозитория launcher, рабочих каталогов сборки, CI и поставляемого приложения

Инструмент требует интерактивную консоль и запрашивает пароль при выполнении команды

Пароль не передается через аргументы командной строки или переменные окружения

---

## Ограничения результата

Манифест подписывается без изменения его содержимого

Существующий файл подписи или публичного ключа не перезаписывается

После подписания байты манифеста не должны изменяться перед публикацией

Доступность опубликованных URI и проверка подписи полученных по ним байтов выполняются отдельно согласно политике первой
публикации
