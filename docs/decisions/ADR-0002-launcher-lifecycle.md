# ADR-0002 Launcher lifecycle

## Статус

approved

## Контекст

Необходимо определить жизненный цикл Launcher

## Решение

Launcher работает как конечный автомат

Все переходы происходят через LauncherStateMachine

Каждый успешный переход публикует событие в EventBus

## Последствия

UI полностью реагирует на события

LauncherEngine больше не занимается публикацией событий

Новые состояния добавляются централизованно
