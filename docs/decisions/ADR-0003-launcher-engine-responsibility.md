# ADR-0003 LauncherEngine Responsibility

## Статус
Accepted

## Контекст

LauncherEngine управляет жизненным циклом запуска приложения.

Пока сценарий запуска представляет собой линейное выполнение TaskPipeline.

В будущем возможны более сложные сценарии:

- повтор этапов
- отмена
- восстановление
- безопасный режим

## Решение

На текущем этапе LauncherEngine напрямую использует TaskPipeline.

Отдельный LaunchOrchestrator не вводится

## Последствия

+ Простая архитектура
+ Минимальное количество абстракций

- При усложнении сценариев LauncherEngine может начать расти

## Будущие изменения

При появлении нескольких сценариев запуска рассмотреть выделение LaunchOrchestrator

LauncherEngine отвечает за:

- управление жизненным циклом
- запуск Operation
- обработку результата выполнения


LauncherEngine не отвечает за:

- загрузку файлов
- авторизацию
- проверку ресурсов
- работу с UI
