# ADR-0004 - Проверка одного файла

## Статус

Accepted

## Контекст

Необходимо проверить соответствие локального файла данным из Manifest

## Решение

Создать отдельный FileVerifier, отвечающий за проверку одного файла.
VerificationService отвечает только за координацию проверки множества файлов.

## Последствия

+ Простая интеграция многопоточности.
+ FileVerifier можно тестировать изолированно.
+ VerificationService не знает деталей проверки.

## Альтернативы

1. Выполнить всю проверку внутри VerificationService.
2. Передать проверку в HashVerifier.
