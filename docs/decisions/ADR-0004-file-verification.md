# ADR-0004 — Проверка одного файла

## Статус

Accepted

---

## Контекст

Необходимо проверить соответствие локального файла данным из `Manifest`

Проверка множества файлов состоит из повторяющихся проверок файлов

Необходимо разделить ответственность между проверкой одного файла и координацией проверки
множества файлов

---

## Решение

Создать отдельный `FileVerifier`, отвечающий за проверку одного файла

`VerificationService` отвечает за координацию проверки множества файлов и не содержит
деталей алгоритма проверки отдельного файла

`FileVerifier` использует `HashService` для выполнения проверки хеша файла

Таким образом, ответственность разделена между

- `FileVerifier` - проверка одного файла и определение результата проверки
- `HashService` - вычисление и работа с хешем файла
- `VerificationService` - координация проверки множества файлов

---

## Последствия

- `FileVerifier` можно тестировать изолировано
- `VerificationService` не знает деталей проверки одного файла
- `HashService` можно использовать независимо от координации проверки
- Проверку отдельных файлов можно выполнять независимо
- Архитектура допускает последующее добавление многопоточности без изменения ответственности `FileVerifier`

---

## Альтернативы

1. Выполнить всю проверку внутри VerificationService
2. Использовать отдельный `HashVerifier` для проверки файла

`HashVerifier` был рассмотрен как вариант декомпозиции на раннем этапе разработки

В текущей архитектуре `HashVerifier` не используется

Проверка файла выполняется через `FileVerifier`, а операции с хешем вынесены в `HashService`
