# ADR-0005 - Неизменяемые объекты предметной области

## Статус

Accepted

## Контекст

Объекты VerificationReport и FileVerificationResult представляют результат уже завершенной операции

## Решение

Использовать неизменяемые объекты (immutable).

## Причины

- Потокобезопасность
- Предсказуемость
- Простота тестирования
- Невозможность нарушить инварианты после создания

## Последствия

Все изменения состояния представляются созданием нового объекта, а не изменением существующего
