# ADR-0006 Authentication Boundaries

## Статус

Accepted

## Контекст

Подсистема авторизации включает несколько компонентов, каждый из которых
отвечает за отдельную часть процесса

Без явного определения границ ответственности существует риск того, что SessionManager,
AuthenticationProvider, LaunchContext и будущие HTTP-клиенты начнут дублировать обязанности
друг друга

Цель данного ADR - зафиксировать зоны ответственности компонентов и определить правила
взаимодействия между ними

## Решение
| Компонент              | Ответственность                                                                           |
|------------------------|-------------------------------------------------------------------------------------------|
| AuthenticationProvider | Выполняет аутентификацию пользователя и создает новую Session                             |
| SessionManager         | Хранит текущую Session, управляет ее жизненным циклом и предоставляет SessionHandle       |
| SessionHandle          | Временный объект доступа к активной Session во время выполнения операции                  |
| LaunchContext          | Содержит данные текущего сценария запускаю Не является хранилищем пользовательской сессии |
| LauncherTask           | Использует только SessionHandle, не взаимодействует напрямую с SessionManager             |

## Границы

AuthenticationProvider:
- Не хранит Session
- Не управляет жизненным циклом Session
- Не взаимодействует с UI напрямую

SessionManager:
- Не выполняет аутентификацию
- Не делает HTTP-запросы
- Не знает о конкретном способе получения токена

LaunchContext:
- Не хранит глобальное состояние приложения
- Не управляет авторизацией
- Не заменяет SessionManager

## Последствия

Положительные:
- Уменьшается связанность между компонентами
- Session может быть изменена без влияния на остальные подсистемы
- Упрощается тестирование
- Появляется возможность заменить механизм аутентификации без изменения LauncherTask

Отрицательные:
- Увеличивается количество небольших классов
- Требуется больше объектов при сборке приложения
