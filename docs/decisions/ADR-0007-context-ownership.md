# ADR-0007 Context Ownership

# Контекст

На текущем этапе LaunchContext создается в LauncherEngine, поскольку существует единственный
сценарий запуска

При появлении нескольких типов операций ответственность за создание контекста будет перенесена
в соответствующую Operation
