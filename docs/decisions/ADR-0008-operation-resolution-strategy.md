# ADR-0008 Operation Resolution Strategy

## Статус
Deferred

## Контекст

При увеличении количества LauncherOperation может потребоваться централизованная координация
условий их запуска

## Возможные причины

- Состояние Session
- Состояние Launcher
- Доступность сети
- Выбранный профиль
- Состояние Manifest
- Политика запуска

## Решение

На текущем этапе OperationResolver обеспечивает достаточный уровень абстракции

В случае роста количества условий может быть выделен OperationOrchestrator
