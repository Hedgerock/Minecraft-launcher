# ADR-0010 Execution Strategy Selection

## Статус

Proposed

## Контекст

В текущей версии LaunchOperation самостоятельно выбирает ExecutionStrategy

При дальнейшем развитии системы выбор стратегии может быть делегирован отдельному
ExecutionPlanner, принимающему решение на основе характеристик операции и среды выполнения

ExecutionStrategy не создает механизм исполнения самостоятельно. Стратегия получает его извне
через абстракцию, форма которой будет определена при появлении конкретных требований
