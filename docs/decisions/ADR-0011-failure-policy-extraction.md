# ADR-0011 Failure Policy Extraction

## Статус

Proposed

## Контекст

В настоящий момент все операции используют единственный сценарий обработки ошибок

## Decision

Политика обработки ошибок остается внутри соответствующей LaunchOperation

## Consequences

При появлении нескольких независимых сценариев обработки ошибок допускается выделение
отдельного компонента FailurePolicy

До этого момента дополнительная абстракция считается преждевременной
