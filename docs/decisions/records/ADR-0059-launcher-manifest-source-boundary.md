# ADR-0059: Определить границу источника manifest URI для запуска из UI

## Статус

Accepted

> Примечание: решение реализовано в итерациях
> `feat(app): load manifest URI from local configuration`
> `feat(app): wire local startup configuration`

---

## Контекст

На момент принятия решения CLI и JavaFX entrypoint используют `LauncherConfigurationResolver` из `launcher-app`

Resolver получает manifest URI из аргумента запуска или подставляет `https://localhost:8080/manifest.json`

Полученный URI становится частью `LauncherConfiguration` и используется существующим flow загрузки манифеста

Минимальный `launcher-ui` не содержит выбора источника манифеста

Значение `localhost` поддерживает локальный запуск при наличии соответствующего сервера, но не определяет источник манифеста
для пользовательского приложения

Перед дальнейшим развитием UI необходимо определить, какой слой отвечает за предоставление manifest URI и должен ли
технический адрес становиться частью основного пользовательского сценария

---

## Решение

Источник manifest URI для запуска из UI определяется до создания launcher lifecycle

`launcher-app` владеет границей преобразования исходной конфигурации запуска в `LauncherConfiguration`

`LauncherConfiguration.manifestUri` остается подготовленным входным значением для существующего flow загрузки манифеста

`launcher-core` и операции launcher lifecycle не выбирают источник manifest URI

Минимальный `launcher-ui` не предлагает ввод произвольного manifest URI как основное действие запуска

Явный manifest URI в аргументах запуска сохраняется как технический способ запуска и использует общий
`LauncherConfiguration` и launcher lifecycle

Значение `localhost`, подставляемое на момент принятия решения, не считается источником манифеста для пользовательского
приложения

Конкретный способ предоставления исходной конфигурации для UI определяется отдельно

---

## Рассмотренные варианты

### Вводить произвольный manifest URI на launch screen

Вариант отклонен для основного сценария запуска

Технический адрес стал бы обязательной частью пользовательского взаимодействия, хотя минимальный UI предназначен для
запуска уже подготовленной конфигурации

### Считать localhost URI источником манифеста для пользовательского приложения

Вариант отклонен

Доступность локального сервера зависит от окружения и не обеспечивается launcher

### Сразу ввести хранение и выбор профилей запуска

Вариант отложен

Граница источника manifest URI не определяет формат профиля, способ хранения настроек и пользовательский сценарий их выбора

---

## Последствия

Ответственность за предоставление manifest URI остается за внешней конфигурацией запуска, а не переносится в launcher
lifecycle или элементы минимального UI

Существующий технический запуск с явным URI сохраняет общий путь выполнения

Текущая подстановка `localhost` может оставаться временным поведением реализации, но не является решением для пользовательского
запуска

Для пользовательского запуска из UI потребуется конкретный источник конфигурации

Текущий URI по умолчанию такой гарантии не дает

Отказ от ввода произвольного URI на launch screen ограничивает ручную настройку через UI, но не исключает будущий выбор
подготовленного профиля или версии игры

---

## Не входит в решение

- Формат и место хранения конфигурации запуска
- Модель профилей и выбор версии игры
- Получение manifest URI от удаленного сервиса
- UI для настройки источника манифеста
- Поведение при отсутствии или ошибке исходной конфигурации
- Выбор launcher directory
- Источник configured Java override
- Отдельный runtime dev mode или UI smoke-сценарий
