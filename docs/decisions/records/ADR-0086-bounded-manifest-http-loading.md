# ADR-0086: Определить границу ограниченной HTTP-загрузки манифеста и подписи

## Статус

Accepted

---

## Контекст

На момент принятия решения launcher-api получает манифест и отдельную подпись через LauncherHttpClient

JavaLauncherHttpClient накапливает тело ответа без прикладного ограничения размера и не задает общий deadline получения
ответа

Проверка HTTP status выполняется после получения тела

Проверка подписи согласно [ADR-0070](ADR-0070-managed-manifest-authenticity-boundary.md) предшествует преобразованию JSON,
но не ограничивает ресурсы, затраченные на получение неподтвержденных байтов

Манифест и подпись имеют разное назначение и требуют отдельных ограничений размера ответа

Необходимо ограничить ожидание и накопление данных на HTTP-границе до передачи результата потребителям

---

## Решение

launcher-api владеет ограничениями HTTP-загрузки манифеста и подписи

Каждый запрос через LauncherHttpClient получает неизменяемые HttpRequestLimits с общим временным бюджетом и максимальным
размером тела ответа в байтах

HttpManifestClient и HttpManifestSignatureClient передают ограничения согласно назначению загружаемого ресурса

Значения по умолчанию определяются в launcher-api отдельно для манифеста и подписи и не принимаются из сетевого ответа

JavaLauncherHttpClient применяет переданные ограничения и не определяет назначение ресурса по его URI

Общий deadline охватывает выполнение запроса от начала HTTP-загрузки до полного получения тела

Получение заголовков и поступление очередной части тела не начинают временной бюджет заново

Время установления соединения ограничивается отдельно и не продлевает общий deadline запроса

Максимальный размер проверяется при поступлении байтов до их добавления в накапливаемый результат

Content-Length может использоваться для раннего отказа, но не заменяет контроль фактически полученных байтов

Недопустимый HTTP status не требует полного вычитывания тела ответа

Превышение размера, истечение deadline или ошибка передачи завершают загрузку ошибкой без возврата частичного результата

При отказе инициируется отмена незавершенного обмена и освобождение принадлежащих ему ресурсов

Cleanup не добавляет неограниченного ожидания и не подменяет исходную причину отказа

Прерывание ожидания сохраняет interrupt status вызывающего потока

Ограничения применяются к управляемому манифесту и техническим способам загрузки

Требования HTTPS для управляемого источника, запрет перенаправлений и действующие правила декодирования сохраняются

Исходные байты управляемого манифеста передаются на проверку подписи без преобразования

launcher-app сохраняет ответственность за сборку компонентов

Сетевые ограничения не передаются в LauncherConfiguration или launcher-core

---

## Рассмотренные варианты

### Ограничить только установление соединения

Вариант отклонён

Установленное соединение не исключает задержку заголовков или остановку передачи тела

Ограничение соединения не заменяет общий deadline загрузки

### Проверять размер после полного получения ответа

Вариант отклонён

Проверка готового массива или строки не ограничивает накопление данных до завершения передачи

Отказ должен происходить при превышении допустимого размера, а не после получения всего ответа

---

## Последствия

HTTP-граница получает явные ограничения ожидания и накопления тела ответа

Загрузка манифеста и подписи использует отдельные бюджеты без изменения доменных моделей

Медленный или превышающий установленный размер ответ может быть отклонен даже при корректном содержимом

Значения по умолчанию требуют сопровождения при росте публикуемого манифеста

Ограничение тела не является гарантией общего предела памяти JVM или внутренних буферов HTTP client

Отмена обмена прекращает ожидание результата приложением, но не гарантирует мгновенного освобождения сетевых ресурсов
реализацией JDK

Deadline применяется к отдельному HTTP-запросу и не определяет общий deadline launcher lifecycle

Изменения требуют regression coverage для превышения размера, задержки ответа, остановки передачи тела, прерывания
и сохранения действующих правил загрузки

---

## Не входит в решение

- Ограничение загрузки файлов в launcher-downloader
- Ограничение сетевого получения vanilla assets в launcher-preparer
- Retry, backoff, resume или автоматический fallback
- Пользовательская настройка сетевых параметров
- Общий сетевой модуль или универсальный HTTP framework
- Domain concurrency model и параллельное выполнение operations
- Пользовательская cancellation launcher lifecycle
- Изменение алгоритма подписи, доверенных ключей или политики публикации
