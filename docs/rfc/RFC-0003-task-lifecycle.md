# RFC-0003 Task Lifecycle

## Статус
Draft

## Контекст

Launcher выполняет сценарий запуска как последовательность LauncherTask

По мере развития проекта задачи становятся более сложными:

- Появляются длительные операции
- Появляются параллельные операции
- Появляется возможность отмены
- Появляется необходимость корректного завершения

Необходимо определить единый жизненный цикл LauncherTask

## Жизненный цикл задачи

```text
CREATED
  |
  ▼
READY
  |
  ▼
RUNNING
  |
  |
  ┌───────────────────┐
  |                   |
  |                   |
  ▼                   ▼
COMPLETED           FAILED
  |
  ▼
DISPOSED
```

## Инварианты

|-1

Каждая задача проходит состояние CREATED только один раз

|-2

После перехода в RUNNING задача не возвращается в READY

|-3

После завершения задача больше не может быть повторно запущена

|-4

Каждый экземпляр LauncherTask выполняется только один раз

|-5

Verification никогда не использует результаты предыдущего запуска

|-6

Любая длительная операция сначала строит план выполнения, а затем начинает изменять состояние системы
