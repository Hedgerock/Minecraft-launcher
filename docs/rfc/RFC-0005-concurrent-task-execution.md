# Concurrent Task Execution

## Цель

Определить правила, при которых Launcher может выполнять задачи параллельно без нарушения
архитектурных инвариантов

## Правила

### C-1

Параллельно могут выполняться только независимые LauncherTask

### C-2

Operation остается владельцем жизненного цикла всех своих задач

### C-3

Параллельное выполнение не должно изменять архитектурные границы компонентов

### C-4

Результат Operation не зависит от порядка выполнения независимых задач

### C-5

ExecutionStrategy отвечает за выполнение задач, но не принимает бизнес-решений по результатам
их выполнения

## C-6

Завершение LaunchOperation определяется достижение согласованного архитектурного состояния, а
не окончанием выполнения отдельных LauncherTask

## Motivation

Последовательно выполнение LauncherTask обеспечивает простую модель исполнения, однако не
позволяет эффективно использовать вычислительные ресурсы при обработке независимых задач
(например, проверки большого количества файлов)

Настоящий документ определяет ограничения, при которых допускается безопасное параллельное
выполнение задач без нарушения существующей архитектуры Launcher
